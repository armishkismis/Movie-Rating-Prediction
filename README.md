# 🎬 Movie Rating Prediction

A Python-based Data Analysis project that explores movie datasets to analyze ratings, genres, popularity, and other factors influencing movie success. This project includes data cleaning, feature engineering, exploratory data analysis (EDA), and visualizations to uncover meaningful insights.

---

## 📌 Project Overview

The goal of this project is to analyze movie data and understand the factors that influence movie ratings and success.

The project covers:

- Data Cleaning
- Data Preprocessing
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Visualization

---

## 📂 Dataset

**Source:** IMDb Movies India Dataset (CSV)

The dataset includes the following features:

- Movie Name
- Year
- Duration
- Genre
- Rating
- Votes
- Director
- Actors

---

- Pandas

## 🔧 Data Cleaning

The following preprocessing steps were performed:

- Cleaned the **Duration** column by removing "min" and converting it to numeric format.
- Cleaned the **Votes** column by removing commas and converting it to numeric values.
- Converted **Year** and **Rating** into appropriate numeric data types.
- Converted categorical columns such as Genre, Director, and Actors into category data types.
- Removed missing values from important columns.
- Removed duplicate records.

---

## ⚙️ Feature Engineering

The dataset was prepared for analysis by:

- Converting data types
- Handling missing values
- Cleaning text columns
- Preparing categorical variables

## 📊 Exploratory Data Analysis (EDA)

The following analyses were performed:

- Movie Ratings Distribution
- Movies Released Per Year
- Top Movie Genres
- Duration vs Rating
- Votes vs Rating
- Top Directors Analysis

---

## 📈 Visualizations

The project includes:

- Histogram of Movie Ratings
- Line Chart of Movies Released Per Year
- Bar Chart of Top Genres
- Scatter Plot of Duration vs Rating
- Scatter Plot of Votes vs Rating
- Bar Chart of Top Directors

---

## 💡 Key Insights

- Movies with higher vote counts generally have more stable ratings.
- Popular genres receive more audience engagement.
- Most movies have an average runtime.
- Ratings vary across different genres.
- Votes and popularity significantly influence movie success.
